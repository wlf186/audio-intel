# 表达优化请求包实测（2026-11）

## 结论与适用范围

重新验证后的 `qwen3.5:9b` 使用请求包，将多个细分单元、复核及小结合并处理。下表中旧流程至少20次调用的每次新试验均不超过旧流程的10%；四个短来源仍各用2次，不声称短任务下降九成。其他模型和未重新验证的旧配置沿用原策略。

用户要求精简验收并将剩余时间控制在2小时内。保留11份来源、15组模式的27次新流程性能测量；两份开发长稿三种模式各3轮，其他组1轮。质量完整核查覆盖10组开发稿及3组独立来源，另2组独立中稿仅报告性能：对话正文已读，但小结未完成全量判读；中等视频稿未完成质量判读。不能称为15组全部质量通过，也未完成最初12来源、36组、每组3轮的大范围计划。

## 方法

- 旧流程提交 `4f8261cad01635039ea74996b223869db8a13136`，27次新流程均实际运行不可变提交 `00443e4bdd6df6d5ed5dfe08fdf09041c0de2f47`。后续运行时修改仅为新任务阅读/导出视图的句末段落整理；存储稿、生成、复核请求和检查点不变，全部实测正文的非空白字符保持一致。73项针对性测试通过。最终段落层没有重新运行完整模型计时和物理写入试验，不把旧测量冒充最终提交的新测量。
- Ollama 0.40.3；9B模型digest `56671c2ab9385f9cfcb404638e32cd62d88e3501d44822208363c010179a3c90`；客户端32K/输出4K tokens、服务端观察窗口64K、关闭思考。验证后发送presence_penalty=0及JSON Schema；高级参数显式值和null优先，不换模型/精度。
- 隔离新旧试验均用10000次上限测完整流程；正式长期预算300次保持原值。所有实际HTTP尝试、修复、失败及恢复计入。长开发组C0取3次完整旧流程最小值，单轮组取该次值；C0≥20要求每次新调用≤floor(C0/10)，短任务≤2。
- 耗时包含优化开始至发布、隔离API退出及SQLite WAL收尾，请求串行。三轮组耗时报告中位数，单轮重复性证据较弱。
- 写入为Linux隔离API及线程 `/proc/self/io write_bytes-cancelled_write_bytes`，包括WAL收尾，排除夹具/报告准备和Ollama容器。每次新写入均不高于所选旧流程最小值。这是应用侧写入证据，不是SSD NAND磨损或整机/模型服务器写入测量。新实现不增加磁盘缓存或逐token日志，来源索引仅在任务内存。
- AI按完整原文核对正文、全部原细分小结、画面标题及新增父级小结；完整组先冻结A/B判断再解码。相同来源、类型及文本会复用既有判断，不称为新盲测。未听原始音频，没有人工认证。问题项按来源对应项去重，不是事实准确率。

独立长音频原始盲评可读性下降0.608/5，超过0.5门槛，判为失败。随后只增加阅读视图的句末分段，未改字词、数字、问题或存稿；42个变化后的完整单元逐项复验。该复验已知标签，不是新盲测、也不是新模型试验：新均分3.677，案例等权下降0.489，来源字符加权下降仍为0.503。原始失败评分和事实批注保留，不能据此声称长稿质量无损。

密集口语仍可能残留重复、漏细节、误解名称或强化条件与意见，保守基础整理不等于流畅重写。短问题能保留疑问形式；短稿小结仍可能过于笼统，其他已测开发短稿曾把出发时间套到集合时间。来源拦截及独立复核只保护部分错误，不证明全部事实正确。

英文视频画面可能截断半句话；首尾片段保留原词，中间完整句才改写。英文视频小结、标题使用模型选择且程序验证的原文主题词，界面标为“关键词”。信息量弱于句式摘要，可能省去否定、近似或意见范围，不应视为已验证关系；英文音频仍用句式小结。正文“模型参与”也不代表每个词都改写。全部原细分小结保留，新增父级不能代替它们。

## 失败、回归与复核挑战

此前一份中稿留出对照虽调用达标，却出现其他段落话题及已有组件变成新产物，完整判断后拒绝该版。加入任务内存来源拦截后，该已知来源3轮回归均17次，未再发现上述两类问题；仍有省略和小结误解。这是已知来源回归，不计新独立验证。替换中对话来源仅按元数据选定、校验和先冻结，开发组通过后才首次读原文；本次时间内只完成其性能及正文读取，没有把它记为质量通过。

固定复核挑战另有60条含20条预置改变、12条长稿含6条改变，每组3轮；候选实际33次HTTP、216个判断。旧/新分别为17/20与19/20，长稿同为4/6，没有增加合理候选误报，仍漏2/6长稿改变。实际挑战提交 `3e1609e9c81b27d773aeee73839c4beea8980100`，通过11完整请求及216判定一致性核对后复用；不冒充当前生成、计时或写入。

定型前还拒绝了密集口语退化、引号邻词误删、英文串文、否定/人物关系改变和大量无用摘取等策略。失败结果不混入当前性能均值；不以问题总数较低抵消实质串文。
